Implementation contracts

* TRust schedules checkpoints at Engine::next_atomics_wait_deadline() for resident
  pages, parser waits, workers and suspended audio worklets. Finite waits keep the
  owning event loop alive until settlement, followed by the usual microtask
  checkpoint. Timer and ordinary-task ordering are preserved. Cross-origin
  isolation is enabled only in the test host for these browser regressions.
* Cold ordinary synchronous author functions containing loops obey the call
  threshold. Self-hosted methods still compile on their first call; async/generator
  coroutine paths retain their eager bytecode policy. Whole-frame transfer excludes
  suspending frames. After 128 executed AST backedges, supported body-level loops
  transfer the existing function activation to its whole bytecode continuation;
  other supported loops
  use checked fragments while enclosing environments, handlers and cleanup stay
  parked. Parameters, declarations and prefix effects are not replayed. The
  interpreter tier stays interpreted; bytecode stops at the VM; the JIT tier can
  enter a borrowed native continuation in that same invocation. VM admission uses
  128 edges and 4,096 weighted work units, with at most eight bounded retries.
  Unsupported entries retain their prior path. Loops owned by static snapshot
  run_once functions retain the VM-only bootstrap policy; separately owned nested
  or eval code is not suppressed merely because it runs below such a frame.
* Ordinary native invocations advance existing inlining hotness consistently
  across generic/AST dispatch and checked call-cache fills. Guarded cache hits
  retain their existing accounting; borrowed-frame admission remains separate.
  This lets warmed callers reach the established feedback/inlining thresholds
  when loop compilation is deferred.
* All uncaptured homes transferred from the AST move their current Value ownership
  into pinned PackedValue Cells; parked bindings retain identity and attributes
  without retaining stale values. Captured/eval-homed bindings keep their original
  environments. Scoped aliases give mapped arguments the canonical slot. Shared
  VM/native slices avoid overlapping exclusive borrows. Native register homes
  publish before author callbacks and reload afterwards. Scope teardown restores
  every parked binding before unregistering aliases and clearing/recycling slots,
  including abrupt exit and host interruption. Unsupported projected evaluators
  use an environment-backed fallback. Borrowed code is excluded from ordinary call
  caches, shared-context direct calls and optional optimizing admission hooks.
* Guarded ordinary dense arrays use contiguous storage with spare space at both
  ends: shift is O(1), and unshift is amortized O(1) per inserted item. Geometric
  growth occasionally moves the live range. Descriptors, holes, prototypes and
  proxies retain the general algorithms. Numeric mirrors and native accesses
  follow the logical start; runtime layout probes fail closed on incompatible
  headers. The deque retains NonNull's storage proof. A cached descriptor proof
  uses InlinePacked padding, preserving its length/data layout and avoiding a
  separate flag word. x64 array operations retain checked helpers. The inherited
  concat species/proxy snapshot failure is also fixed.
* DataView converts arguments in specified order before taking one backing-store
  witness and access borrow or shared-buffer lock. Primitive arguments avoid
  redundant conversion and native activation setup. Object conversions retain the
  checked path, including detachment, resize and exception identity.
* Built-in slots, private elements and auto-accessor backing state use an
  inaccessible map within the existing lazy property-storage sidecar. Ordinary
  object bodies retain their baseline size/allocation class. This map is separate
  from ordinary keys, descriptors and lookup; strings such as "#\0co_locale" remain
  author properties and cannot read, replace or forge engine state. Internal reads
  invoke no getter or Proxy trap. Property copies omit slots/private brands;
  replacing Array.fill's ordinary payload preserves the receiver's slots. GC,
  cycle breaking, teardown and retained-memory accounting include slot owners.
  Private writes remain valid after freeze. The supported Stage 3
  nonextensible-applies-to-private proposal still rejects new private additions
  with Proxy-aware extensibility checks. Node v24.21.0 lacks that proposal and is
  explicitly not the oracle for its permissive private-stamping behavior.
* Ordinary strings beginning with NUL cannot forge Symbol identities or internal
  markers. Key encoding/decoding covers JavaScript and public host boundaries;
  observable names retain source spelling. JSON.rawJSON's marker uses slot storage.
* The 256 MiB buffer cap becomes Node/V8's non-sandbox validation limit: 2^53 - 1
  bytes on 64-bit and 2^31 - 1 on 32-bit. Allocation remains fallible. Resizable and
  growable buffers reserve maxByteLength; only their initial logical length is
  explicitly initialized, and growth zeroes newly exposed bytes. Transfer validates
  and reserves before detaching, moves the backing owner and invalidates the source
  native witness. Preserving resizability rejects lengths above maxByteLength;
  fixed transfer may grow beyond it.
* Shared buffers own reference-counted backing blocks through a weak identity
  registry. Views, queued broadcasts and pending waits retain ownership. The last
  owner frees storage/removes its identity; agent teardown unregisters waiters.
* Getters, setters and conversions invoked by checked operations retain their
  logical inlined activation for caller reflection, strictness and stack positions,
  including reentrant throws and GC. Inline-only metadata caches the logical
  position for each checked operation, so implicit marker publication is O(1);
  guards restore the prior marker on return, throw or continuation. Native paths
  that invoke no author code require no implicit marker publication.
